HOW TO ADD YOUR PROJECT PHOTOS
================================

Drop each photo into the matching folder below using the EXACT filename
listed. The website is already wired up to load these, as soon as a file
appears at the right path it replaces the placeholder tile automatically,
on the homepage "Our Work" slideshow and on the /gallery page. No code
changes needed.

Tips:
- Landscape photos, roughly 1600x1200px or larger, work best.
- Keep file sizes under ~1.5MB each (export at ~80% JPEG quality) so the
  site stays fast.
- Want more photos than the list above, or different categories? Add new
  entries to lib/gallery.ts (src path + alt text + category) and drop the
  matching file in the same folder.
